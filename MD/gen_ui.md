# IMPORTANT DOMAIN LOGIC

Do not treat all similarity as identical material.

The application must distinguish:

## IDENTICAL

Technically equivalent material with matching critical attributes.

## DUPLICATE

The same material represented by redundant material records/codes.

## NEAR-DUPLICATE

Highly similar material but with differences or missing technical attributes.

## FUNCTIONALLY EQUIVALENT

Materials that can perform the same function but are not necessarily technically identical.

## RELATED

Materials that are related but cannot be considered equivalent.

The UI must reflect these distinctions wherever the Stitch design shows relationship types.
